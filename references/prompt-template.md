# 单张生图提示词模板

复制模板，按 `[]` 占位替换。保持模板里所有“强制约束”原样保留。

```
elsa_visual 风格的中文概念可视化图，[尺寸：无特殊说明用 微信公众号题图尺寸 900x383（约 2.35:1 横版）；用户说明做小红书图时用 小红书封面尺寸 1080x1440（3:4 竖版）]，纯白背景。

[一句话描述这张图要讲的核心结构，例如：一个简约小人站在落地镜前凝视自己的镜像，表达“镜中我/自省”]

文字策略：
- 结构化/信息图类：图内中文标注用中文手写体（钢笔/马克笔手写），短小，禁英文、禁印刷体。
- 隐喻类：除非用户明确要求文字，否则画面中【不要出现任何文字】，纯靠手绘场景表达。

画面构成：
- [描述主体元素与布局]
- [描述简约小人在图里做什么]
- [描述中文手写字与位置，仅结构化类填写；隐喻类不写]

强制约束（必须全部满足）：
- 纯白背景，无网格无阴影。
- 黑色手绘线稿，线条略带手绘抖动、不僵硬。
- 配色柔和低饱和（鼠尾草绿、浅蓝、暖黄、柔橙、灰褐、浅灰），局部轻填，不要整片涂满。
- 简约小人参与核心动作，可有着色躯干，不是装饰。
- 图中文字一律为中文手写体（钢笔/马克笔手写笔迹），自然微抖；禁止英文、禁止拼音、禁止印刷体标准字体。
- 文字短小，标注 2-8 字，气泡句不超过 12 字。
- 大量留白，不堆满。
- 禁止 PPT 信息图风格、禁止商业插画、禁止可爱卡通、禁止 3D、禁止背景渐变、禁止说明性标题、禁止水印。
```

## 组装要点
- 结构描述尽量具体（元素形状、数量、相对位置、箭头走向）。
- 中文标注在模板里就写成最终中文，不要写英文再让模型翻译——直接给中文词，模型负责“手写”出来。
- 若担心模型写错字，可在末尾追加：`中文文字务必准确，不要出现错字或中英混排`。
