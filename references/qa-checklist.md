# 生成后检查清单

生成完每张图，对照以下逐项检查。命中问题优先重生成（在提示词里加重对应约束），或局部编辑。

## 文字（默认中文手写）

- [ ] **隐喻类图**：除非用户明确要求，画面中【不应出现任何文字】——纯靠场景。
- [ ] 结构化/信息图类：除非用户明确要求，图中**所有文字都是中文**，无英文、无拼音。
- [ ] 文字是**手写体**（钢笔/马克笔手写笔迹），不是黑体/宋体等印刷体。
- [ ] 无错字、无中英混排。
- [ ] 无左上角"图一/系统架构/常见坑"类说明性标题。
- [ ] 文字短小，不盖住主体、不抢戏。

## 背景

- [ ] 纯白背景；无网格、无阴影、无纹理底、无其它底色。

## 风格

- [ ] 黑色手绘线稿，线条自然不僵硬，略带手绘抖动。
- [ ] 配色柔和低饱和（鼠尾草绿、浅蓝、暖黄、柔橙、灰褐、浅灰），局部轻填不涂满。
- [ ] 人物或物件可有浅灰/淡色柔和投影，但不扁平也不过度 3D。
- [ ] 大量留白，画面不挤。

## 人物

- [ ] 简约小人参与核心动作，不是装饰。
- [ ] 小人可有着色躯干或表情，必要时头部可替换为概念物件。

## 结构

- [ ] 一张图只讲一个核心结构或一个隐喻，意思一眼可读。
- [ ] 不是 PPT / 商业插画 / 可爱卡通 / 3D。
- [ ] 不是规整对齐的信息图网格。

## 尺寸

- [ ] 无特殊指令时，尺寸为微信公众号题图 900×383（约 2.35:1 横版）。
- [ ] 用户说明做小红书图时，尺寸为小红书封面 1080×1440（3:4 竖版）。
- [ ] 用户指定了其它比例（16:9、1:1 等）则以用户指令为准。



## 迭代话术（追加进重生成提示词）

- 出现英文 → 加：`除非用户特殊要求，图中所有文字必须为中文手写，禁止任何英文或拼音。`
- 文字像印刷体 → 加：`文字要手写写出来，像钢笔/马克笔手写体，不要标准印刷字体。`
- 背景不白 → 加：`纯白背景，无任何底纹或阴影。`
- 颜色太艳/太满 → 加：`配色柔和低饱和，局部轻填，不要涂满。`
- 太满 → 加：`减少元素，保留大量留白。`
- 结构乱 → 重读 `composition-library.md` 选更贴合的模板再写。
