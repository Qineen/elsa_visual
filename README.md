# elsa_sketch 简约手绘概念可视化图 Skill

> 把一段文字内容可视化，画成一张白底的、手绘的、elsa_sketch风格的配图。
>
> 图中文字默认中文手写体，默认微信公众号题图尺寸。

## 适合谁用

- 需要为文章、公众号、小红书做**题图 / 封面 / 配图**的内容创作者。
- 想把抽象概念（认知、方法、模型、对比）**可视化**但不想画成枯燥 PPT 的人。
- 喜欢"简约手绘 + 柔和点缀 + 一看就懂"画风，而非商业插画或卡通的人。
- 已在使用此风格，希望把这套画风**标准化、可复用**地批量产出的人。

## 它会产出什么

- **单张 PNG 概念图**（每张图只讲一个结构或一个隐喻）。
- 两种画幅（按指令自动选）：
  - 默认：微信公众号题图 **900×383（约 2.35:1 横版）**。
  - 用户说明做小红书图时：小红书封面 **1080×1440（3:4 竖版）**。
- 两类呈现：
  - **结构化 / 信息图类**：比如，左右二分、线性流程、象限、对话等。
  - **隐喻类**：纯靠手绘场景讲故事，默认**不出现任何文字**（除非你要求加）。



## 视觉风格

- **纯白背景** + 大量留白，干净不挤。
- **黑色手绘线稿**，线条略带抖动、不僵硬，有"手画感"。
- **柔和低饱和配色**：鼠尾草绿、浅蓝、暖黄、柔橙、灰褐、浅灰，仅局部轻填，不涂满。
- **浅灰 / 淡色柔和投影**给人物与物件增加一点层次，不扁平也不过度 3D。
- **简约小人**常有着色躯干，且必须**参与核心动作**，不是装饰。
- 图中文字默认一律**中文手写体**（钢笔 / 马克笔笔迹），无英文、无拼音、无印刷体。



## 安装方法

1. 解压本压缩包，得到 `elsa_sketch/` 文件夹。
2. 将其整体放入你的Codex 或 WorkBuddy 的 skills 目录中，例如：
  ```
   C:\Users\<你的用户名>\.workbuddy\skills\elsa_sketch\
  ```
3. 重启 / 刷新会话，你的 AI Agent 会自动发现并加载该 skill。
4. 验证：对话中输入 `elsa sketch` 应触发本 skill。

> 在workBuddy中生图，独立计费，约 5–10 credits / 张。

## 工作流程

1. **消化输入**：判断内容量。
  - 内容多 → 结构化呈现（信息图 / 可视化）。
  - 内容少 → 用隐喻呈现（默认不加文字）。
2. **选结构 + 写中文标注**：从结构模板库挑 1 种（可混搭 / 可超出）或发明，加必要文字标注。
3. **写单张提示词**：套用 `references/prompt-template.md` 模板（已强制包含画风约束）。
4. **生成**：用 `ImageGen` 单张生成；按指令选 900×383 或 1080×1440。
5. **检查与迭代**：对照 `references/qa-checklist.md`（文字 / 背景 / 风格 / 人物 / 结构 / 尺寸），命中问题就重生成并加重对应约束。
6. **保存交付**：存到 workspace 内 `assets/<topic-slug>-elsa-sketch/`，保留原始文件不覆盖。

## 注意事项

- **参考图是风格校准，不是固定产出**：新图应基于这套画风自由发明新构图，不要照抄参考图的布局、物件或英文标注。
- **默认无文字的隐喻图**：除非你明确要求，隐喻类图画面中不应有任何文字——文字会削弱"一看就懂"。
- **尺寸规则**：未特别说明 → 公众号 900×383；说明"小红书" → 1080×1440；其它比例以你指令为准。
- **纯白底**：背景必须纯白，无网格 / 阴影 / 纹理 / 其它底色。
- **不满足的画风会被判为失败**：PPT 信息图、商业插画、可爱卡通、3D、背景渐变、说明性标题、水印，都不符合要求。
- **生成可能产生水印**：部分模型会在角落自动加"AI生成"小标识，非 prompt 要求，实际使用时通常裁掉即可。
- **README 不影响产出**：本文件只是文档，改它不会改任何生成结果；真正驱动生成的是 `SKILL.md` 与 `references/`。
